# Easy Living Home

Website for **Easy Living Home** — practical organization and comfort products for women 55+.

## Live Site

**https://crimsondesert1985-png.github.io/easy-living-home/**

## Pages

- `index.html` — Home
- `shop.html` — Product collection with Facebook Shop links
- `about.html` — Brand story
- `contact.html` — Contact form (demo)

## Design

Soft neutrals (cream, sage, warm beige), elegant serif headings, clean modern body text. Fully responsive.
